# Roteiro do projeto (checklist)

Os detalhes de cada etapa estão na seção 7 da apostila.

- [ ] 1. Configurar o Git (nome e e-mail) e instalar o GitHub CLI
- [ ] 2. Transformar esta pasta em repositório e fazer o primeiro commit
- [ ] 3. Criar o repositório no GitHub e enviar (push)
- [ ] 4. Criar uma branch, mudar o título da página e abrir um pull request
- [ ] 5. Abrir uma issue: "Mostrar o consumo médio por pessoa"
- [ ] 6. Pedir ao Claude Code (no app) que resolva a issue e abra um pull request
- [ ] 7. Revisar o pull request do Claude, testar e fazer o merge
- [ ] 8. (Opcional) Ativar o @claude no GitHub e publicar a página com GitHub Pages
