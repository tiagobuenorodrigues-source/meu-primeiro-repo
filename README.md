# Calculadora de Consumo de Água

Página web simples que calcula o consumo de água a partir de duas leituras do hidrômetro.

Este repositório é o projeto prático da apostila **GitHub + Claude, do zero ao primeiro projeto**.

## Como usar

Abra o arquivo `index.html` no navegador (duplo clique). Informe a leitura anterior,
a leitura atual e os dias do período, e clique em **Calcular**.

## Arquivos

| Arquivo | Para que serve |
| --- | --- |
| `index.html` | A página e a lógica do cálculo |
| `estilo.css` | A aparência da página |
| `CLAUDE.md` | Instruções que o Claude lê antes de mexer no projeto |
| `.gitignore` | Lista do que o Git deve ignorar |
| `extras/claude.yml` | Workflow que deixa o Claude responder a `@claude` no GitHub (etapa 8) |
| `ROTEIRO.md` | Checklist das 8 etapas do projeto |
