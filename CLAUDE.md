# Instruções para o Claude

Este arquivo é lido automaticamente pelo Claude Code quando ele trabalha neste repositório.
Escreva aqui as regras do projeto, como faria com um colega novo.

- Projeto: calculadora de consumo de água em HTML, CSS e JavaScript puro, sem bibliotecas.
- Idioma: todo texto da página, comentários e mensagens de commit em português do Brasil.
- Unidades: leituras em m³; resultados diários em litros (1 m³ = 1000 litros).
- Mantenha tudo em `index.html` e `estilo.css`; não crie arquivos novos sem necessidade.
- Antes de abrir um pull request, descreva o que mudou e como testar.
